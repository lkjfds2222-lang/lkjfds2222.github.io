# 雞省研究所｜肯德基優惠券比價網站

這是一個可離線使用、也可自行部署的靜態網站，包含 2026 年 10 月 18 日整理的 53 張肯德基台灣優惠券。

## 立即使用

- 雙擊 `index.html`，用瀏覽器開啟即可，無須安裝任何軟體。
- 選擇人數與餐點數量，再按「立即找出最省組合」。
- 用下方搜尋欄尋找優惠券，點「複製券碼」，到官方網站確認後使用。

## 公開成網址

最簡單：把 `index.html` 拖曳到 Netlify Drop (https://app.netlify.com/drop)，服務會提供一個可公開存取的網址。請自行閱讀並確認該服務的使用規則。

另一種方式：建立 GitHub 儲存庫，上傳 `index.html`，再在 Settings > Pages 中啟用從主要分支部署。

## 資料和限制

- 資料整理日：2026-10-18。
- 優惠券價格、有效期限、組合內容以當時整理的公開網頁資訊為準。
- `index.html` 自身**不會自動更新資料**，但會依台灣日期隱藏到期券；請定期人工維護。
- 裡面嵌入優惠資料於 `const COUPONS`。另附 `coupons.json` 方便後續改版。
- 單張優惠券是否能重複兌換、是否受理多張券、口味能否替換，以及部分門市排除等限制，以官方結帳/門市為準。
- 準確的比較範圍只有網站中收錄的優惠券，未涵蓋單點價格、會員點數、外送費和第三方平台折扣。
- 不會上傳餐點偏好或收藏；收藏只存於使用者的瀏覽器。
